# WifiController 🛜🚪

> **O problema:** Seus familiares entram no banheiro com o celular e parecem esquecer que o tempo passa, transformando o banheiro em um escritório privado.
>
> **A solução:** Uma aplicação desktop desenvolvida em .NET 10 que permite ativar ou desativar o Wi-Fi da sua casa com apenas um clique (mantendo o Ethernet funcionando normalmente). Ideal para fazer as pessoas saírem mais rápido do banheiro ou para aquela trolagem "saudável" com os amigos.

---

## 🚀 Como Funciona

O aplicativo oferece uma interface gráfica simples onde você insere os dados de acesso do seu roteador. Ao clicar no botão, o app envia os comandos necessários para ligar ou desligar o rádio sem fio (Wi-Fi), sem interromper a conexão via cabo de rede.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** C#
* **Framework:** .NET 10 (Desktop)

## 📦 Como Usar

1. **Pré-requisitos:** Certifique-se de ter o [.NET 10 Runtime](https://dotnet.microsoft.com/download) instalado na sua máquina.
2. **Download:** Baixe a versão mais recente na aba de *Releases* ou clone o repositório.
3. **Execução:**
   * Abra o aplicativo.
   * Preencha os campos com o **Host** (IP do roteador, ex: `192.168.1.1`), **Usuário** e **Senha**.
   * Clique em **Desativar Wi-Fi** para iniciar a operação "Banheiro Livre".
   * Clique em **Ativar Wi-Fi** para devolver a paz à casa.
